# Lombiq MSBuild SDK - UI Testing Libraries

This SDK configures reusable libraries containing Orchard Core UI test methods and helpers. It supplies the [Lombiq.Tests.UI](https://github.com/Lombiq/UI-Testing-Toolbox) dependency and keeps the output as a library, without adding an executable test runner.

Use [Lombiq.MSBuild.OrchardCore.Tests.UI.Sdk](../Lombiq.MSBuild.OrchardCore.Tests.UI.Sdk/Readme.md) for projects that discover and run UI tests. See [Using MSBuild SDKs](../Docs/UsingMSBuildSdks.md) for setup.
